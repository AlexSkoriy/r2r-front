# Как залить код на GitHub — с вашего Mac

Это делается один раз, занимает две минуты. После этого сервер сможет забирать
код сам, и мы вернёмся к обычному ходу работ.

## Почему это делаете вы, а не я

Токен, который вы прислали, рабочий — я им прочитал репозиторий и убедился,
что он пустой. Но моя песочница пропускает запись в чужие репозитории только
через собственный список разрешённых, а ваш в этом списке не значится. Проверка
происходит до того, как дело доходит до токена, так что от прав токена тут ничего
не зависит.

Ваш компьютер такого ограничения не имеет. Поэтому проще всего залить код с него.

---

## Шаг 1. Скачать файл проекта

Я прислал в чат файл `r2r-front.bundle`. Скачайте его — он попадёт в «Загрузки».
Это весь проект вместе с историей правок, упакованный в один файл.

Если у вас уже лежит старый `r2r-dev.bundle` — он устарел, берите новый.

## Шаг 2. Открыть терминал

`Cmd + Пробел` → наберите `Терминал` → Enter.

## Шаг 3. Выполнить четыре команды

По одной, каждая с Enter в конце. Здесь копирование работает нормально — это ваш
Mac, а не консоль сервера.

```bash
cd ~/Downloads
git clone r2r-front.bundle r2r-front
cd r2r-front
git remote set-url origin https://github.com/AlexSkoriy/r2r-front.git
git push -u origin main
```

Разберём, что происходит: первая команда переходит в «Загрузки», вторая распаковывает
проект в папку `r2r-front`, третья говорит ему «твой дом теперь на GitHub», четвёртая
отправляет туда всю историю.

**На последней команде спросят логин и пароль:**

- **Username:** `AlexSkoriy`
- **Password:** вставьте **токен** `github_pat_...`, а не пароль от GitHub.
  Обычный пароль GitHub для этого не подходит и будет отвергнут.

При вводе пароля символы не отображаются — это нормально.

Если Mac предложит установить инструменты разработчика (Xcode Command Line Tools) —
согласитесь, это нужно для работы `git`, ставится само, минут пять.

## Шаг 4. Проверить

Откройте `https://github.com/AlexSkoriy/r2r-front` в браузере. Должны увидеть список
файлов и надпись про 15 коммитов. Напишите мне, когда увидите, — и переходим ко второй
части инструкции `ДЕВ-ПОШАГОВО.md`, той что выполняется на сервере.

---

## Если что-то пошло не так

**`git: command not found`** — Mac предложит установить инструменты разработчика,
согласитесь и повторите.

**`Authentication failed`** — почти всегда вставлен пароль от GitHub вместо токена.
Возьмите строку, начинающуюся с `github_pat_`.

**`destination path 'r2r-front' already exists`** — папка от прошлой попытки.
Удалите её: `rm -rf ~/Downloads/r2r-front` и начните с шага 3 заново.

**`Repository not found`** — проверьте, что репозиторий на GitHub действительно создан
и называется ровно `r2r-front`.

В любом непонятном случае пришлите мне текст ошибки целиком.

## Что дальше

После этого шага правки будут ходить так: я меняю код у себя → присылаю вам
изменения → вы отправляете их на GitHub одной командой `git push` → сервер забирает.

Если в приложении Claude найдётся возможность добавить репозиторий GitHub как
источник для этого чата (там же, где вы подключали папку с Google Drive), то и этот
промежуточный шаг отпадёт: я смогу отправлять код напрямую. Посмотрите, есть ли такая
кнопка, — но это не срочно и работе не мешает.
